# ڕێکخستنی ئیندیکەیتەرەکانی LAOL (BETA 1 / BETA 2.5)

## 🎉 هەواڵی باش: هیچ گۆڕانکارییەک لە Pine پێویست نییە

کاتێک کۆدەکەم شیکردەوە، بینیم کە ئیندیکەیتەرەکەت **پێشتر `alert()` ی تێدایە**
و JSON دەنێرێت:

```json
{"id":"1699999999-12","signal":"BULL_CONFIRMED","action":"BUY",
 "symbol":"XAUUSD","tf":"1","entry":3350.25,"sl":3345.10,
 "tp":3391.45,"tp_alt":3354.25}
```

بۆیە لەبری دەستکاریکردنی کۆدەکەت، **ئەدەپتەرێکم لە سێرڤەرەکە دروستکرد** کە
ئەم فۆرماتە بەڕاستەوخۆ وەردەگرێت. کۆدی Pine ـەکەت **دەقاودەق وەک خۆی دەمێنێتەوە**.

---

## ١) URL ی وێبهۆک

بۆ هەر ئیندیکەیتەرێک URL ێکی جیاواز بەکاربهێنە — ناوی کۆتایی دەبێتە
ناسنامەی سەرچاوە لە سیستەمی confluence دا:

```
BETA 1:    https://your-server.com/webhook/laol/laol-beta1?secret=YOUR_SECRET
BETA 2.5:  https://your-server.com/webhook/laol/laol-beta25?secret=YOUR_SECRET
```

لە TradingView:
1. ئەلێرت دروست بکە → Condition = ئیندیکەیتەرەکە
2. **"Any alert() function call"** هەڵبژێرە
3. Message: **بەتاڵی بهێڵەرەوە** (ئیندیکەیتەرەکە خۆی JSON دروست دەکات)
4. Webhook URL = ئەوەی سەرەوە
5. Expiration = Open-ended

---

## ٢) مۆدی گواستنەوەی تەواو (PASSTHROUGH) — بنەڕەت

بەپێی داواکاریت، سیستەمەکە لە **مۆدی گواستنەوەی تەواو** دایە:

| شت | دۆخ |
|---|---|
| هەموو جۆرەکانی سیگناڵ | ✅ دەگوازرێنەوە — بەبێ جیاوازی |
| `FORMING` / `CONFIRMED` / `FINAL_ENTRY` | ✅ هەموویان چالاک |
| SL / TP | لە ئیندیکەیتەرەکەوە — **دەستکاری ناکرێت** |
| Risk : Reward | 1:8 وەک خۆی |
| ژمارەی پۆزیشنی کراوە | **بێ سنوور** |
| ژمارەی ترەیدی ڕۆژانە | **بێ سنوور** |
| فیلتەری سپرێد / سێشن | ناچالاک |
| Trailing / Break-even | ناچالاک |
| Confluence | ناچالاک |
| پێچەوانەکردنی پۆزیشن | ناچالاک — پۆزیشنەکان لێک جیان |

تەنها دوو شت کاردەکەن:
1. **Kill switch** — دوگمەی PANIC لە داشبۆرد (کۆنترۆڵی تۆ)
2. **پشکنینی ئاراستەی SL** — ئەگەر BUY بێت بەڵام SL لەسەرەوەی entry بێت،
   ڕەت دەکرێتەوە. ئەمە فیلتەری ستراتیژی **نییە** — ئۆردەرێکی وا لای
   بڕۆکەریش ڕەت دەکرێتەوە (invalid stops)، بۆیە پێشتر دەیگرین.

### جۆرەکانی سیگناڵ

| سیگناڵ | ئاراستە | دۆخ |
|---|---|---|
| `BULL_FORMING` / `BEAR_FORMING` | BUY / SELL | ✅ ترەید دەکات |
| `BULL_CONFIRMED` / `BEAR_CONFIRMED` | BUY / SELL | ✅ ترەید دەکات |
| `FINAL_ENTRY_BULL` / `FINAL_ENTRY_BEAR` | BUY / SELL | ✅ ترەید دەکات |
| `*_LAOL_*_TAKEN` | — | ➖ زانیاری (بکەرەوە ئەگەر بتەوێت) |

سیگناڵی `*_TAKEN` لە ناو Pine دا هیچ `entry`/`sl`/`tp` ێکی نییە — تەنها
ئاگادارکردنەوەیە کە ئاستێکی LAOL بردرا. بۆیە بە بنەڕەت ترەید ناکات.
ئەگەر بتەوێت، لە داشبۆرد بیکەرەوە.

### سیگناڵی نەناسراو

ئەگەر ئیندیکەیتەری دووەم ناوی سیگناڵی جیاوازی هەبێت، سیستەمەکە خۆی
ئاراستەکە دەدۆزێتەوە لە ناوەکەوە (`BULL`/`LONG`/`BUY` → کڕین،
`BEAR`/`SHORT`/`SELL` → فرۆشتن). واتە **هیچ سیگناڵێک نافەوتێت**.

---

## ٣) کام TP بەکاربهێنرێت؟

ئیندیکەیتەرەکەت دوو TP دەنێرێت:

| خانە | لە Pine | بنەڕەت |
|---|---|---|
| `tp` | `entry ± (range × 8)` — **RR = 1:8** | ✅ بەکاردێت |
| `tp_alt` | `entry ± 40 pip` | بەردەستە |

بنەڕەت `tp` ـە چونکە RR ی 1:8 ی ئیندیکەیتەرەکەت پارێزراو دەبێت.

---

## ٤) قەبارەی لۆت

SL/TP لە ئیندیکەیتەرەوە دێن، بەڵام **قەبارەی لۆت** هێشتا لەلایەن تۆوە
دیاری دەکرێت لە داشبۆرد:

- `risk_pct` — ڕێژەی مەترسی لە ئیکویتی (بنەڕەت ٠.٥٪). EA خۆی لۆت
  حیساب دەکات بەپێی دووری SL ی ئیندیکەیتەر.
- `fixed_lot` — ئەگەر > 0 بێت، هەمیشە هەمان لۆت.
- `max_lot` — بەربەستی دڵنیایی.

> لەبەر ئەوەی پۆزیشنەکان بێ سنوورن، ئاگاداری `risk_pct` بە. ١٠ پۆزیشنی
> کراوە بە ٠.٥٪ = ٥٪ مەترسی پێکەوە.

---

## ٥) هەردوو ئیندیکەیتەر پێکەوە (ئارەزوومەندانە)

> ⚠ لە مۆدی passthrough دا confluence **ناچالاکە** — هەموو سیگناڵێک
> بەتەنیا ترەید دەکات. ئەم بەشە تەنها بۆ داهاتووە ئەگەر بتەوێت.

ئەگەر ڕۆژێک بتەوێت هەردووکیان پێکەوە بێن، سەرەتا passthrough بکوژێنەوە
دواتر:

```bash
curl -X POST http://localhost:8000/api/confluence/sources \
  -H 'Content-Type: application/json' \
  -d '{"sources": {"laol-beta1": 1.0, "laol-beta25": 1.0}}'
```

### نموونەی کارکردن (تاقیکراوەتەوە ✓)

```
BETA 1  → BULL_CONFIRMED  (sl=3344, tp_alt=3354)  →  چاوەڕوانی: laol-beta25
BETA 2.5→ FINAL_ENTRY_BULL (sl=3342, tp_alt=3354.50) →  ✓ ترەید کرا
ئەنجام: sl=3342.0 (دوورترین)  tp=3354.0 (نزیکترین)
```

## ٦) idempotency

`signal_id` بەم شێوەیە دروست دەکرێت:
```
laol-beta1-BULL_CONFIRMED-1699999999-2
   سەرچاوە    جۆری سیگناڵ    id ی ناو Pine
```

لەبەر ئەوەی ئیندیکەیتەرەکەت `signal_counter` ی بێهاوتای هەیە، هەرگیز
هەمان ترەید دوو جار ناکرێتەوە — تەنانەت ئەگەر TradingView پەیامەکە
دووبارە بنێرێتەوە.

---

## ٧) تێبینی تەکنیکی لەسەر کۆدەکەت

شتانێک کە لە شیکردنەوەدا بینیم (بۆ زانیاری تۆ، نەک کێشە):

1. **`strategy.entry()` + `alert()` پێکەوەن** — لەبەر ئەوەی `strategy` ـە،
   دەتوانیت لە TradingView بەکتێستی بکەیت. ئێمە تەنها `alert()` بەکاردەهێنین،
   بۆیە ئەنجامی بەکتێست کاریگەری لەسەر ترەیدە ڕاستەقینەکان نییە.

2. **`pyramiding=20`** — واتە دەتوانێت تا ٢٠ پۆزیشن بکاتەوە. لە سیستەمەکەماندا
   `max_open_positions` ئەمە کۆنترۆڵ دەکات (بنەڕەت ٢).

3. **`request.security(..., lookahead=barmerge.lookahead_off)`** ✓ —
   ئەمە دروستە و repaint ناکات لە داتای HTF دا.

4. **٢٥ فرەیمی کاتی** — ئەگەر ئیندیکەیتەرەکە هێواش بوو، `soft_start`
   بکەرەوە تا تەنها ١٦ فرەیم بەکاربهێنێت.

## قەرەبووکردنەوەی سپرێد (لە EAـەوە)

لە MT5 سپرێد کاریگەری لەسەر شوێنی تەقینەوەی SL/TP هەیە:
**BUY** لە Askـەوە دەکرێتەوە بەڵام SLـەکەی بە **Bid** دەتەقێتەوە؛
**SELL** لە Bidـەوە دەکرێتەوە بەڵام SLـەکەی بە **Ask** دەتەقێتەوە.

بۆیە EAـەکە لە ساتی جێبەجێکردندا سپرێدی ئەو کاتە دەخوێنێتەوە و
**هەمان بڕ دەخاتە سەر هەردوو SL و TP**:

```
BUY : SL = SL_سیگناڵ − سپرێد      TP = TP_سیگناڵ + سپرێد
SELL: SL = SL_سیگناڵ + سپرێد      TP = TP_سیگناڵ − سپرێد
```

چونکە هەمان بڕ لە هەردوو لاوە زیاد دەکرێت، **ڕێژەی R:R وەک خۆی دەمێنێتەوە**
هەروەک ئیندیکەیتەرەکە داینا. هیچ ژمارەیەکی نوێ دانەنراوە — تەنها سپرێدی
ڕاستەقینەی بڕۆکەرەکە.

### نموونە (سپرێد = ١٥ پۆینت = ١.٥ پیپ)

سیگناڵ: entry=3360.00، SL=١٠ پیپ، TP=٨٠ پیپ

| | SL کۆن | SL نوێ | دووری | TP کۆن | TP نوێ | دووری |
|---|---|---|---|---|---|---|
| BUY | 3359.00 | **3358.85** | **١١.٥ پیپ** | 3368.00 | **3368.15** | **٨١.٥ پیپ** |
| SELL | 3361.00 | **3361.15** | **١١.٥ پیپ** | 3352.00 | **3351.85** | **٨١.٥ پیپ** |

### Inputەکان

| input | بنەڕەت | واتا |
|---|---|---|
| `SpreadComp` | `true` | قەرەبووکردنەوەی سپرێد کارا بێت |
| `SpreadExtraPts` | `0` | پۆینتی زیادە لەسەر سپرێد (بۆ نموونە `5` بۆ ئارامی زیاتر) |
| `SpreadCapPts` | `0` | زۆرترین بڕی زیادکراو. `0` = بێ سنوور. بۆ نموونە `30` نایەڵێت لە کاتی نیوزدا SL زۆر فراوان بێت |
| `RespectStopsLevel` | `true` | ئەگەر SL/TP لە کەمترین دووری ڕێپێدراوی بڕۆکەر نزیکتر بوو، بیپاڵێوێتە دەرەوە |

### `RespectStopsLevel` بۆچی گرنگە

بڕۆکەرەکان `SYMBOL_TRADE_STOPS_LEVEL` دادەنێن — کەمترین دووری SL/TP لە نرخەوە.
ئەگەر ئیندیکەیتەر SLـێکی زۆر نزیک بنێرێت، بڕۆکەر بە `Invalid stops` ڕەتی
دەکاتەوە و **سیگناڵەکە بە تەواوی دەفەوتێت**. ئەم پشکنینە ئۆردەرەکە ڕزگار
دەکات بە خستنە دەرەوەی SL/TP بۆ نزیکترین ئاستی ڕێپێدراو. ئەمە پاراستنێکی
تەکنیکییە بەرامبەر بڕۆکەر، **نەک فیلتەری ستراتیژی** — هیچ سیگناڵێک ڕەت ناکرێتەوە.

### لۆگ لە MT5

هەر ئۆردەرێک ئەم دێڕە دەنووسێت لە تابی Experts:

```
laol-beta25-BULL_CONFIRMED-1723 XAUUSD | سپرێد=15p زیادکراو=15p | SL=3358.85 TP=3368.15 | لۆت=0.43
```

### کاریگەری لەسەر لۆت

فراوانکردنی SL واتا دووری مەترسی گەورەتر دەبێت، بۆیە `LotByRisk` خۆکارانە
**لۆتێکی بچووکتر** دەژمێرێت. مەترسییەکەت لەسەر `risk_pct` دەمێنێتەوە.
