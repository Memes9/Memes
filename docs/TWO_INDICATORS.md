# بەکارهێنانی دوو ئیندیکەیتەر پێکەوە (BETA 1 + BETA 2.5)

## بیرۆکەکە

هەر ئیندیکەیتەرێک **بەجیا** ئەلێرتی خۆی دەنێرێت. سێرڤەرەکە دەنگەکان
کۆدەکاتەوە و تەنها کاتێک ترەید دەکات کە شەرتەکانی هاوڕابوون جێبەجێ بن.

```
BETA 1   ──alert──┐
                  ├──► Confluence Engine ──► Risk Engine ──► MT5
BETA 2.5 ──alert──┘
```

**زۆر گرنگ:** لۆجیکی هیچ کام لە ئیندیکەیتەرەکان دەستکاری ناکرێت.
هەردووکیان لە TradingView دەمێننەوە و هەمان ئەنجامی ئێستایان دەبێت.

## سێ شێوازی هاوڕابوون

| شێواز | واتا | کەی بەکاریبهێنە |
|---|---|---|
| `all` | **هەردووکیان** دەبێت هاوڕا بن | کەمترین سیگناڵ، بەڵام بەهێزترین (پێشنیارکراو) |
| `any` | یەکێکیان بەسە | سیگناڵی زیاتر، مەترسی زیاتر |
| `weighted` | کۆی کێشەکان >= کەمترین خاڵ | کاتێک ئیندیکەیتەرێک باوەڕپێکراوترە |

### نموونەی weighted
```
laol-beta1  = 1.0
laol-beta25 = 1.5    ← باوەڕپێکراوتر
min_score   = 1.5
```
ئەنجام: BETA 2.5 بەتەنیا دەتوانێت ترەید بکات، بەڵام BETA 1 بەتەنیا ناتوانێت.

## ماوەی هاوڕابوون (`confluence_window_sec`)

دوو ئیندیکەیتەر بەندە هەرگیز لە **هەمان چرکە**دا سیگناڵ نەدەن. بۆیە دەنگەکان
بۆ ماوەیەک دەمێننەوە:

- **٥ خولەک (٣٠٠)** — بنەڕەت، باشە بۆ M5/M15
- **١٥ خولەک (٩٠٠)** — بۆ M15/H1
- **١ خولەک (٦٠)** — بۆ scalping ی M1

ئەگەر ماوەکە زۆر درێژ بێت، دەنگی کۆن دەبێتە هۆی ترەیدی درەنگ.
ئەگەر زۆر کورت بێت، هەرگیز هاوڕابوون ڕوونادات.

## لۆجیکی flip

ئەگەر BETA 1 سەرەتا **BUY** بنێرێت و پاشان **SELL**، دەنگی کۆنی
خۆکارانە دەسڕدرێتەوە. واتە هەر ئیندیکەیتەرێک تەنها **یەک دەنگی چالاک**
هەیە. ئەمە ڕێگری لە سیگناڵی ناتەبا دەکات.

## دەستپێکردن

### ١. پێناسەکردنی سەرچاوەکان
```bash
curl -X POST http://localhost:8000/api/confluence/sources \
  -H 'Content-Type: application/json' \
  -d '{"sources": {"laol-beta1": 1.0, "laol-beta25": 1.0}}'
```

### ٢. چالاککردن لە داشبۆرد
پانێڵی **«هاوڕابوونی ئیندیکەیتەرەکان»** → کلیلەکە بکەرەوە → شێواز هەڵبژێرە.

### ٣. لە TradingView
- `pine/laol_beta1_alert.pine`  → بۆ BETA 1
- `pine/laol_beta25_alert.pine` → بۆ BETA 2.5

بەشەکە بخە کۆتایی هەر ئیندیکەیتەرێک و `gb_long` / `gb_short` پەیوەست بکە
بە گۆڕاوی سیگناڵەکانی خۆتەوە. دواتر بۆ **هەریەکەیان** ئەلێرتێک دروست بکە
بە هەمان Webhook URL.

⚠ ناوی `gb_source` دەبێت **دەقاودەق** لەگەڵ ناوەکانی `confluence_sources`
بگونجێت، ئەگەرنا سیگناڵەکە هەژمار ناکرێت.

## SL / TP کاتێک هەردوو ئیندیکەیتەر جیاواز دەڵێن

| سیاسەت | کار |
|---|---|
| SL `widest` | دوورترین SL هەڵدەبژێرێت — پارێزراوتر لە stop-out (پێشنیارکراو) |
| SL `tightest` | نزیکترین SL — زیانی کەمتر بەڵام دەرچوونی زووتر |
| TP `nearest` | نزیکترین TP — قازانج زووتر وەردەگرێت (پێشنیارکراو) |
| TP `farthest` | دوورترین TP — قازانجی گەورەتر، ڕێژەی بردنەوەی کەمتر |

## چاودێری لە داشبۆرد

پانێڵی confluence نیشانی دەدات:
- هەر ئیندیکەیتەرێک ئێستا چی دەڵێت (کڕین/فرۆشتن/چاوەڕوان) و تەمەنی دەنگەکەی
- ئەنجامی کۆتایی: هاوڕان / ناکۆکن / بەشێکی هاوڕان
- خشتەی سیگناڵەکان ستوونی **سەرچاوە**ی هەیە بۆ زانینی ئەوەی کێ چی ناردووە
