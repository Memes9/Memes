## ١. سیستەمەکە چۆن کاردەکات

```
┌─────────────────┐
│  TradingView    │  ئیندیکەیتەرەکانت (BETA 1 + BETA 2.5)
│  ئەلێرت دەنێرن  │  لەسەر ١m و ٣m
└────────┬────────┘
         │  HTTPS POST (webhook)
         ▼
┌─────────────────┐
│   پردەکە        │  FastAPI — لەسەر VPS کاردەکات
│  (bridge)       │  • هەموو سیگناڵێک وەردەگرێت
│                 │  • فیلتەری SL > ٥١ پیپ
│                 │  • دژە-دووبارە
│                 │  • داشبۆردی وێب
└────────┬────────┘
         │  EA داوای دەکات (long-polling)
         ▼
┌─────────────────┐
│  GoldBridge EA  │  لە MetaTrader 5
│                 │  • ئۆردەر دەکاتەوە
│                 │  • قەرەبووی سپرێد
│                 │  • Tier 1 / Tier 2
└─────────────────┘
```

**خێرایی:** لە ئەلێرتەوە تا ئۆردەری کراوە ≈ **١٠٥ میلی‌چرکە**.

## ٢. ئەوەی پێویستت پێیەتی

| شت | تێبینی |
|---|---|
| **TradingView بە پلانی Essential** | webhook لە پلانی خۆڕاییدا نییە. نزیکەی $١٤/مانگ |
| **2FA لەسەر هەژماری TradingView** | بەبێ ئەم، webhook کار ناکات |

| **دۆمەینێک بە HTTPS** | TradingView تەنها HTTPSـی سەرتیفیکەتدار قبوڵ دەکات |

> دووبارە ناینێرێتەوە. بۆیە VPS دەبێت ٢٤/٧ کاربکات.

## ٣. دامەزراندن — هەنگاو بە هەنگاو

### ٣.١ کۆدەکە دابەزێنە

```bash
git clone <ناونیشانی-ڕیپۆکەت>
cd Memes
```

### ٣.٢ ژینگەی Python

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
```

> لە Windows: `.venv\Scripts\pip install -r requirements.txt`

### ٣.٣ نهێنییەکان بگۆڕە

**ئەمە هەنگاوی هەرە گرنگە.** بەهای بنەڕەت لە کۆدەکەدان و
هەرکەسێک دەیانزانێت.

فایلی `.env` دروست بکە:

```
TV_SECRET=نهێنیەکی-درێژ-و-ڕێکەوتی-خۆت
EA_TOKEN=تۆکنێکی-درێژ-و-ڕێکەوتی-خۆت
```

نهێنی بەهێز دروست بکە:

```bash
.venv/bin/python3 -c "import secrets; print(secrets.token_urlsafe(32))"
```

دووان دروست بکە — یەکێک بۆ `TV_SECRET`، یەکێک بۆ `EA_TOKEN`.

### ٣.٤ سێرڤەرەکە دەستپێبکە

```bash
.venv/bin/uvicorn app.main:app --host 0.0.0.0 --port 8000
```

بۆ ئەوەی بەردەوام کاربکات لەسەر Windows، وەک **Windows Service**
دایبنێ (بە NSSM) یان لە Task Scheduler بە "At startup".

### ٣.٥ HTTPS

TradingView داوای HTTPSـی سەرتیفیکەتدار دەکات. دوو ڕێگا:

**ئاسانترین — Cloudflare Tunnel** (خۆڕایی، پێویستی بە پۆرتی کراوە نییە):

```bash
cloudflared tunnel --url http://localhost:8000
```

**یان — Nginx + Let's Encrypt** ئەگەر دۆمەینی خۆت هەیە.

## ٤. ڕێکخستنی TradingView

### ٤.١ ناونیشانەکان

| ئیندیکەیتەر | ناونیشانی webhook |
|---|---|
| BETA 1 | `https://دۆمەینەکەت/webhook/laol/laol-beta1?secret=TV_SECRET` |
| BETA 2.5 | `https://دۆمەینەکەت/webhook/laol/laol-beta25?secret=TV_SECRET` |

`TV_SECRET` بگۆڕە بەو نهێنییەی لە `.env`دا دانات.

### ٤.٢ دروستکردنی ئەلێرت

بۆ **هەر ئیندیکەیتەرێک** و **هەر تایمفرەیمێک** ئەلێرتێک دروست بکە.
واتە ٤ ئەلێرت: BETA 1 لەسەر ١m، BETA 1 لەسەر ٣m، BETA 2.5 لەسەر ١m،
BETA 2.5 لەسەر ٣m.

بۆ هەریەکەیان:

1. چارتەکە بکەرەوە لەسەر **XAUUSD** و تایمفرەیمی دروست
2. کلیک لە ئیندیکەیتەرەکە → **Add alert**
3. **Condition**: ئیندیکەیتەرەکە هەڵبژێرە (نەک "Any alert() function call"
   ئەگەر ئیندیکەیتەرەکەت شەرتی دیاریکراوی هەیە)
4. **Trigger**: `Once Per Bar Close`
5. **Expiration**: دوورترین ڕێکەوت (ئەلێرتەکان بەسەردەچن!)
6. **Notifications** → **Webhook URL** → ناونیشانەکەی سەرەوە دابنێ
7. **Message**: ئەوەی ئیندیکەیتەرەکە دەینێرێت وەک خۆی بیهێڵەوە

> ئیندیکەیتەرەکانت پێشتر فۆرماتی خۆیان دەنێرن و پردەکە دەیناسێتەوە.
> **هیچ گۆڕانکارییەک لە کۆدی ئیندیکەیتەرەکاندا مەکە.**

### ٤.٣ پشکنین

دوای دروستکردنی ئەلێرت، لە داشبۆردەکەدا (`http://دۆمەینەکەت:8000`)
دەبێت سیگناڵەکان ببینیت لە بەشی **Signals**.

## ٥. دامەزراندنی EA لە MT5

### ٥.١ کۆپیکردن

1. MetaTrader 5 بکەرەوە
2. **File → Open Data Folder**
3. بڕۆ بۆ `MQL5/Experts/`
4. `mt5/GoldBridgeEA.mq5` لەوێ دابنێ

### ٥.٢ کۆمپایلکردن

1. **MetaEditor** بکەرەوە (F4 لە MT5)
2. `GoldBridgeEA.mq5` بکەرەوە
3. **Compile** (F7)
4. دەبێت `0 errors, 0 warnings` ببینیت

> **تێبینی گرنگ:** EAـەکە لێرە **کۆمپایل نەکراوە** چونکە کۆمپایلەری
> MQL5 لەسەر Linux نییە. سینتاکسەکە بە دەست پشکنراوە (بڕاکێت و
> پەرانتێزەکان هاوسەنگن، هەموو فەنکشنێک پرۆتۆتایپی هەیە)، بەڵام
> **یەکەم کۆمپایل لای تۆ دەبێت**. ئەگەر هەڵەیەک دەرکەوت، تەنها
> پەیامەکەم بۆ بنێرە.

### ٥.٣ ڕێگەدان بە WebRequest

**بەبێ ئەمە EA کار ناکات.**

1. **Tools → Options → Expert Advisors**
2. ✅ **Allow WebRequest for listed URL**
3. ناونیشانی سێرڤەرەکەت زیاد بکە: `https://دۆمەینەکەت`
4. **OK**

### ٥.٤ دانانی EA

1. چارتی **XAUUSD** بکەرەوە (هەر تایمفرەیمێک — EA پشتی بە
   تایمفرەیمی چارت نابەستێت)
2. EAـەکە ڕاکێشە بۆ سەر چارتەکە
3. ✅ **Allow Algo Trading**
4. inputەکان ڕێک بخە (خوارەوە)
5. **OK**

### ٥.٥ inputە گرنگەکان

| input | بەها | تێبینی |
|---|---|---|
| `ServerURL` | `https://دۆمەینەکەت` | بەبێ `/` لە کۆتاییدا |
| `EAToken` | تۆکنەکەی `.env` | دەبێت وەک یەک بن |
| `PollMs` | `100` | مەیگۆڕە |
| `LongPollMs` | `800` | مەیگۆڕە |
| `UseServerSettings` | `true` | ڕێکخستنەکان لە داشبۆردەوە |
| `EnableTrading` | `false` **لە سەرەتادا** | دوای دڵنیابوون بیکە `true` |

> `UseServerSettings = true` مانای ئەوەیە هەموو ژمارەکان لە
> داشبۆردەوە دێن. ئەگەر `false` بێت، EA ژمارەکانی inputی خۆی
> بەکاردەهێنێت.

## ٦. داشبۆرد — هەموو ئۆپشنەکان

داشبۆرد لە `http://دۆمەینەکەت:8000` دەکرێتەوە.

### قەبارەی لۆت

| ئۆپشن | بنەڕەت | واتا |
|---|---|---|
| `lot_mode` | `percent` | `fixed` یان `percent` |
| `fixed_lot` | `0.01` | لۆتی جێگیر (لە مۆدی fixed) |
| `balance_pct` | `1.0` | ڕێژەی باڵانس (لە مۆدی percent) |
| `max_lot` | `1.0` | زۆرترین لۆت |

**مۆدی percent:** `لۆت = (باڵانس ÷ ١٠٠) × ٠.٠١ × ڕێژە`

| باڵانس | ١٪ | ٢٪ |
|---|---|---|
| $١٠٠ | 0.01 | 0.02 |
| $١,٠٠٠ | 0.10 | 0.20 |
| $١٠,٠٠٠ | 1.00 | 2.00 |

> دووری ستۆپ لۆس **هیچ کاریگەرییەکی نییە** لەسەر قەبارەی لۆت.

### فیلتەری SL

| ئۆپشن | بنەڕەت | واتا |
|---|---|---|
| `max_sl_enabled` | `true` | کلیلی کوژاندنەوە |
| `max_sl_pips` | `51` | زۆرترین دووری SL |
| `pip_points` | `10` | پۆینت لە هەر پیپێکدا |

سیگناڵێک کە SLـەکەی **زیاتر لە** ٥١ پیپ بێت ڕەت دەکرێتەوە.
دەقاودەق ٥١ پیپ **قبوڵ دەکرێت**.

### دژە-دووبارە

| ئۆپشن | بنەڕەت | واتا |
|---|---|---|
| `debounce_enabled` | `true` | کلیلی کوژاندنەوە |
| `debounce_sec` | `2.0` | ماوەی پشکنین |

**چی بلۆک دەکات:** تەنها کاتێک هەموو ئەمانە وەک یەکن —
سەرچاوە + سیمبول + ئاراستە + magic + entry + SL + TP.

**چی بلۆک ناکات:**
- سیگناڵی جیاواز بە SL/TPـی جیاواز → دەچێتە ژوورەوە
- BETA 1 و BETA 2.5 بە هەمان setup → **هەردووکیان** دەچنە ژوورەوە
- تایمفرەیمی جیاواز → دەچێتە ژوورەوە
- ئاراستەی پێچەوانە → دەچێتە ژوورەوە

### قەرەبووی سپرێد

| ئۆپشن | بنەڕەت | واتا |
|---|---|---|
| `spread_comp_enabled` | `true` | کلیلی کوژاندنەوە |
| `spread_extra_points` | `0` | پۆینتی زیادە |
| `spread_cap_points` | `0` | سنووری قەرەبوو (٠ = بێ‌سنوور) |
| `respect_stops_level` | `true` | ڕێزگرتن لە سنووری بڕۆکەر |

سپرێد **بە هەمان ڕێژە** لە SL و TP زیاد دەکرێت:

| سپرێد | SL ١٠ پیپ | TP ٨٠ پیپ |
|---|---|---|
| ١٢ پۆینت | 11.2 | 81.2 |
| ١٥ پۆینت | 11.5 | 81.5 |
| ٢٠ پۆینت | 12.0 | 82.0 |

### Tier 1 / Tier 2

| ئۆپشن | بنەڕەت | واتا |
|---|---|---|
| `progression_enabled` | `true` | کلیلی کوژاندنەوە |
| `tier1_trigger_pct` | `30.0` | لە چەند ٪ی TP کاربکات |
| `tier1_lock_pct` | `1.0` | SL بۆ چەند ٪ قازانج |
| `tier2_trigger_pct` | `50.0` | لە چەند ٪ی TP کاربکات |
| `tier2_lock_pct` | `3.0` | SL بۆ چەند ٪ قازانج |
| `tier2_close_pct` | `50.0` | چەند ٪ی لۆت دابخرێت |

### ژمارە magicەکان

|---|---|

## ٧. یاساکان چۆن کاردەکەن

### یاسای ١ — هەموو سیگناڵێک دەبێتە ئۆردەر

پردەکە هیچ سیگناڵێک فیلتەر ناکات جگە لە یاسای ٣. SL و TP
**دەقاودەق** وەک ئیندیکەیتەر ناردوویەتی دەگوازرێنەوە.

ژمارەی پۆزیشنە کراوەکان **سنووردار نییە**.

### یاسای ٢ — magic بۆ هەر تایمفرەیمێک

هەر تایمفرەیمێک ژمارەیەکی جیاوازی هەیە، بۆیە ترەیدەکان تێکەڵ نابن.
هەمان سیگناڵ لەسەر ١m و ٣m دەبێتە **دوو ئۆردەری سەربەخۆ**.

### یاسای ٣ — فیلتەری SL و دژە-دووبارە

سەیری بەشی [داشبۆرد](#٦-داشبۆرد--هەموو-ئۆپشنەکان) بکە.

### یاسای ٤ — Tier 1 / Tier 2

**هەموو شتێک بە ڕێژە — هەرگیز بە پیپی جێگیر.**

| TP | Tier 1 لە | SL دەچێتە | Tier 2 لە | SL دەچێتە |
|---|---|---|---|---|
| ٥٠ پیپ | ١٥.٠ | +٠.٥ | ٢٥.٠ | +١.٥ |
| ١٠٠ پیپ | ٣٠.٠ | +١.٠ | ٥٠.٠ | +٣.٠ |
| ٢٥٠ پیپ | ٧٥.٠ | +٢.٥ | ١٢٥.٠ | +٧.٥ |
| ٨٠٠ پیپ | ٢٤٠.٠ | +٨.٠ | ٤٠٠.٠ | +٢٤.٠ |

**Tier 1 (٣٠٪):** تەنها SL دەجوڵێت. هیچ ناداخرێت.

**Tier 2 (٥٠٪):** نیوەی لۆتەکە دادەخرێت **و** SL دەچێتە +٣٪.
نیوەکەی تر بەردەوام دەبێت تا TPی کۆتایی.

**لۆتی 0.01:** نیوەکردن مەحاڵە، بۆیە **هیچ ناداخرێت** — تەنها SL
دەجوڵێت و پۆزیشنەکە تا TPی کۆتایی بەردەوام دەبێت.

## ٩. چارەسەری کێشەکان

### سیگناڵ نایەت

| پشکنین | چۆن |
|---|---|
| ئەلێرت بەسەرچووە؟ | لە TradingView سەیری Alerts بکە |

| سێرڤەر کاردەکات؟ | داشبۆرد بکەرەوە |

### سیگناڵ دێت بەڵام ئۆردەر ناکرێتەوە

| پشکنین | چۆن |
|---|---|

## ١٠. ئەوەی دەبێت ئاگاداری بیت

### ١٠.١ EA کۆمپایل نەکراوە

کۆمپایلەری MQL5 لەسەر Linux نییە. کۆدەکە بە دەست پشکنراوە بەڵام
**یەکەم کۆمپایل لای تۆ دەبێت**. ئەگەر هەڵە هەبوو، پەیامەکەم بۆ بنێرە.

### ١٠.٢ سیگناڵی فەوتاو

TradingView ئەلێرت **دووبارە نانێرێتەوە**. ئەگەر سێرڤەرەکەت
بۆ ٥ خولەک کوژاوە بێت، هەموو سیگناڵەکانی ئەو ماوەیە **بۆ هەمیشە
فەوتاون**. بۆیە:

- VPS بەکاربهێنە، نەک کۆمپیوتەری ماڵەوە
- سێرڤەرەکە وەک service دابنێ تاوەکو خۆکارانە بگەڕێتەوە
- چاودێری بکە (uptime monitor)

### ١٠.٣ R:R دوای Tier 2

TPی کۆتایی هێشتا ١:٨ ـە، بەڵام لەبەر ئەوەی نیوەی پۆزیشنەکە لە
٥٠٪دا دادەخرێت، **R:Rـی ڕاستەقینەی بەدەستهاتوو کەمترە**. ئەمە
پێشتر پەسەندکراوە.

### ١٠.٤ قەرەبووی سپرێد و R:R

قەرەبووی سپرێد **هەمان بڕ** لە SL و TP زیاد دەکات. ئەمە R:R لە
١:٨ دەباتە نزیکەی ١:٧.١. ئەمەش پەسەندکراوە.

### ١٠.٥ ئەوەی جێبەجێ نەکراوە

- **ئەپی دێسکتۆپی PyQt6** (§١ی سپێسەکەت) — بەئەنقەست نەکراوە.
  داشبۆردی وێب هەمان کار دەکات و لە هەر ئامێرێکەوە کاردەکات.
- **سیگناڵەکانی `*_TAKEN`** — ئێستا وەک زانیاری وەردەگیرێن.
  ئەگەر دەتەوێت ئەوانیش ترەید بکەن، پێم بڵێ.

### ١٠.٦ نهێنییەکان

بەهای بنەڕەت (`change-me-...`) لە کۆدەکەدان و **دەبێت بگۆڕدرێن**
پێش بەکارهێنانی ڕاستەقینە.
